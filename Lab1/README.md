# Lab1

**Петрушин Александр, К4141**

- `Order`: обработка и группировка заказов с использованием функций высшего порядка. Получение сумм оплаченных и неоплаченных заказов, уникальных имён клиентов и промокодов.
- `Point`: двумерная точка с координатами `x` и `y`, перемещение, вычисление расстояния до начала координат, соответствие протоколам `Equatable` и `Hashable`.
- `Rectangle`: прямоугольник с вычисляемыми площадью, периметром и центром, масштабированием и проверкой попадания точки внутрь.
- `PriorityQueue<Element>`: реализация приоритетной очереди с операциями добавления и извлечения элементов в порядке приоритета.

**Запуск:** открыть `Разработка_ЛР_1.swift` в Xcode или выполнить файл через Swift:

```bash
swift Разработка_ЛР_1.swift
```

Лабораторная работа представляет собой набор задач на структуры данных, вычисляемые свойства, протоколы и функции высшего порядка в Swift.
