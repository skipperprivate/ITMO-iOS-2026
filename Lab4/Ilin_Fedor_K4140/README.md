# Lab4

[Weatherly: Persist favorite cities with SwiftData](https://github.com/barashik07/Weatherly/commit/68e424b23db7702963da1f88d1e3a556c1879390)

• SwiftData сохраняет избранные города и их порядок между запусками. CRUD: `addFavorite`, `loadFavorites`, `moveFavorite`, `removeFavorite`.

• UserDefaults уже хранит настройки единиц температуры, скорости ветра, давления и темы через `UserDefaultsSettingsRepository`.
