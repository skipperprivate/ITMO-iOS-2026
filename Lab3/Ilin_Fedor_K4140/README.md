Lab3: приложение с двумя экранами организовано по MVVM. `Model` генерирует число, `ViewModel` хранит состояние экрана, `View` отображает интерфейс, `App` запускает приложение.

Запуск: открыть `lab3_mvvm.xcodeproj` в Xcode 26.2 или новее, выбрать схему `lab3_mvvm` и симулятор iPhone с iOS 26.2 или новее, нажать Run.
