# Разработка ЛР 5 — Петрушин Александр, К4141

## Цель работы

Рассмотреть применение асинхронного выполнения и средств конкурентности в приложении Weatherly.

## Реализация

В работе используются Swift Concurrency (`async/await`), сетевой клиент, ограничение количества одновременных сетевых операций и объединение совпадающих запросов прогноза погоды. ViewModel взаимодействуют с репозиториями, а сетевые операции и поведение репозиториев проверяются модульными тестами.

## Основные компоненты

- `ConcurrencyLimiter.swift` — ограничение параллельных операций.
- `NetworkClient.swift` — выполнение сетевых запросов.
- `CoalescingWeatherRepository.swift` — объединение совпадающих запросов.
- `OpenMeteoWeatherRepository.swift` — получение прогноза погоды.
- `WeatherRepositoryProtocol.swift` — контракт репозитория прогноза.
- `ConcurrencyLimiterTests.swift` и `CoalescingWeatherRepositoryTests.swift` — тесты соответствующих компонентов.

## Структура

- `Sources/` — исходные файлы, относящиеся к сетевому взаимодействию и конкурентному выполнению.
- `Tests/` — тесты сетевого слоя и репозиториев.

## Технологии

Swift, Swift Concurrency, URLSession, XCTest, Open-Meteo API.

## Запуск

Файлы являются частью проекта Weatherly. Для запуска приложения откройте `Weatherly.xcodeproj` в Xcode. Тесты запускаются через Test Navigator или сочетанием `⌘U` после выбора схемы `Weatherly`.
