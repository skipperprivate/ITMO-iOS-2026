# Lab 8 — SwiftLint

В проект подключён SwiftLint для контроля code style.

## Установка

SwiftLint установлен через Homebrew:

brew install swiftlint

## Подключение к Xcode

SwiftLint добавлен в Build Phases основного target `QuotesOfTheDay`.

При каждой сборке проекта выполняется проверка исходного кода.

Тестовые targets не проверяются.

## Конфигурация

Настройки находятся в `.swiftlint.yml`.

Дополнительно включены правила:

- `force_unwrapping` — предупреждает об опасном использовании `!`
- `sorted_imports` — проверяет порядок импортов
- `empty_count` — рекомендует `.isEmpty` вместо `count == 0`
- `modifier_order` — проверяет порядок модификаторов
- `closure_spacing` — проверяет форматирование closures

Также настроены ограничения длины строк, функций, типов и файлов.

## Результат до исправления

SwiftLint проверил 17 файлов.

Результат:

23 violations, 0 serious.

Основные найденные нарушения:

- `trailing_whitespace`
- `sorted_imports`

## Исправление

Для автоматического исправления использовалась команда:

swiftlint --fix

После этого была выполнена повторная проверка.

## Результат после исправления

SwiftLint проверил 17 файлов.

Результат:

0 violations, 0 serious.

Таким образом основной код приложения приведён в соответствие с настроенными правилами SwiftLint.
