# AbsoluteCinema

Приложение для поиска фильмов, личных оценок и списка «Хочу посмотреть».

## Возможности

- Поиск, подборка популярных фильмов и подробная карточка через TMDB.
- Оценки от 1 до 10, комментарии и список желаемого с локальным сохранением.
- Отправка сохранённой оценки в TMDB через гостевую сессию.
- Сортировка оценок и история открытых фильмов.

## Реализация

SwiftUI, MVVM, iOS 17+. SwiftData хранит оценки и желаемое, UserDefaults — настройки и историю. Сетевые запросы используют async/await; JSON разбирается в actor сетевого клиента. Постеры подготавливаются асинхронно, интерфейс обновляется на MainActor.

## Тесты и линтер

6 unit-тестов и 2 UI-теста на XCTest проверяют поиск, сохранение и отмену оценки, защиту данных и независимость списка желаемого. UI-тесты используют подставные ответы API и базу в памяти. Запуск тестов — Product → Test.

SwiftLint подключён к сборке Xcode; правила находятся в `.swiftlint.yml`. Линтер должен быть установлен локально, иначе сборка выводит предупреждение.
