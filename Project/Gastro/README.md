# Gastro

Итоговый проект по iOS — приложение рецептов на SwiftUI с архитектурой VIPER.

## Авторы

- Первов Дмитрий — К4140
- Задисенцев Дмитрий — К4141

## Возможности

Просмотр рецептов из DummyJSON, создание и редактирование локальных рецептов в SwiftData, GET/POST-запросы, обработка ошибок через тосты.

## Запуск

Открыть `Gastro.xcodeproj` в Xcode 27, выбрать схему `Untitled Project` и iOS Simulator, нажать ⌘R.

## Тесты

7 юнит-тестов и 6 UI-тестов на XCTest. Запуск — ⌘U. UI-тесты используют отдельное хранилище в памяти и заданные ответы URLProtocol без реальных сетевых запросов.

Известная проблема: на iOS 27 три UI-теста (создание, редактирование и публикация) падают при вводе шага из-за перекрытия поля нижней панелью при открытой клавиатуре. На iOS 18.4 ранее проходили все 10 тестов.

## Дополнительно

Карточки рецептов можно свайпать: вправо — в избранное, влево — пропустить. Избранное сохраняется локально между запусками. Доступны вкладки рекомендаций, всех рецептов и избранного.

SwiftLint запускается при сборке и показывает предупреждения, не останавливая сборку из-за нарушений стиля. Установка: `brew install swiftlint`. Правила находятся в `.swiftlint.yml`, форматирование — в `.swift-format`.
