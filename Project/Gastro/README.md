# Gastro

Итоговый проект по iOS — приложение рецептов на SwiftUI с архитектурой VIPER.

## Авторы

- Первов Дмитрий — К4140
- Задисенцев Дмитрий — К4141

## Возможности

Просмотр рецептов из DummyJSON, создание и редактирование локальных рецептов в SwiftData, GET/POST-запросы, обработка ошибок через тосты.

## Запуск

Открыть `Untitled Project.xcodeproj` в Xcode 27, выбрать схему `Untitled Project` и iOS Simulator, нажать ⌘R.

## Тесты

5 юнит-тестов и 5 UI-тестов на XCTest. Запуск — ⌘U. UI-тесты используют отдельное хранилище в памяти и заданные ответы URLProtocol без реальных сетевых запросов.

Известная проблема: на iOS 27 три UI-теста (создание, редактирование и публикация) падают при вводе шага из-за перекрытия поля нижней панелью при открытой клавиатуре. На iOS 18.4 ранее проходили все 10 тестов.
