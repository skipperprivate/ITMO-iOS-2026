# Lab2

**Петрушин Александр, К4141**

Приложение для iOS на Swift с двумя экранами.

- **Первый экран (`ViewController.swift`)**: отображает число и содержит кнопку генерации случайного числа в диапазоне от 1 до 300.
- **Переход на второй экран**: кнопка «Открыть второй экран» выполняет навигационный переход с помощью `UINavigationController`.
- **Второй экран (`SecondViewController.swift`)**: отображает системную иконку звезды и текст «Погода супер!».
- **Интерфейс**: создан программно с использованием UIKit и Auto Layout.
- **Навигация**: настройка корневого контроллера выполняется в `SceneDelegate.swift`.

**Запуск:** открыть `Разработка_ЛР_2.xcodeproj` в Xcode, выбрать схему приложения и симулятор iPhone, затем нажать Run.
